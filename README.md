# Solmara Smart Fridge Roast

A one-line roast of a smart home gadget for make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins" bounty. The entry program writes a single roast line to `/output/entry.txt` — pure Python 3.13 standard library, deterministic, no network.

The entry line:

> My smart fridge photographs me every time I open it after midnight, so my midnight snacking now has its own mugshot collection.

Run it with `python3 main.py` and it writes the line to `/output/entry.txt`.
